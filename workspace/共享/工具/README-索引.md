## 九、约定

1. **新代码不许直接写状态文件**：走 `_状态.mjs` / `自主状态.mjs` / `账本.mjs` / `表.mjs`。
2. **一个事实一个判据**：睡没睡问 `睡态`，在岗问 `占用`，精力问 `恢复目标`，位置问 `移动`。
3. **插件侧不 import 工具脚本**：工具通过 `execFileSync` 或 JSON 文件交接，判据要同步维护。
4. **改完必跑**：`自检.mjs`、`契约检查.mjs`、`生活体检.mjs`；插件改动再加 `round197`。
5. **备份不进顶层**：`*.bak` / `*.pre-*` / `patch_*` 一律进 `/root/bak2/` 或 `_归档/`。
6. **资产/物品写入**：要么走 `改档`，要么整段持 `资产.json` / `物品.json` 锁；禁止锁外读整档再写回。
