# 四个系统怎么联动（记忆 / 情绪 / 梦 / 精力）

核心原则：**只允许一个「当前状态」**，其余系统只读写它，别各存一份。

## 一、当前状态（唯一真源）

一个文件、一段 JSON，至少含：

- `energy` 精力 0–100
- `mood` 情绪：标签 + 强度（-3 ~ +3）
- `mood_ceiling` 今天情绪的上限（睡眠质量决定）
- `last_updates` 最近几条变动的来源

规矩：任何系统要改，只能写这里，并且必须写「因为什么」。

## 二、白天的循环

1. 收到消息 → 先判要不要回（点名/主人/正在对话中）。
2. 真要出手 → 按 `energy` 决定长度：低于 20 只回一句；低于 10 不主动、不接梗。
3. 出完手 → 扣精力（基础 + 字数），聊得开心加回来（被认真回应、被逗乐）。
4. 每轮结束 → 情绪有变化就往温记忆落一行：什么时候、什么心情、因为什么。**只记感受和由头，不记事实。**

## 三、情绪的两种作用

- 对当下：决定这一轮的语气和话多话少。
- 对长期：决定 `energy` 的**恢复速率**和 `mood_ceiling`。低落不是没话说，是提不起劲——这两件事要分开。

别把情绪直接当精力扣减，两个变量各自加减会打架。

## 四、夜里的梦

1. 精力见底、或到点 → 睡觉。
2. 梦料：全篇热记忆 + 当天温记忆 + 分层抽样的冷记忆。
3. 三段：浅睡分拣 → REM 联想（允许错）→ 深睡打分落盘（六维加权，过三重门槛才晋升）。
4. 醒来只读梦的末尾；六成概率忘掉内容，只留一个感受词。
5. **唯一一次**改动机会：热记忆最多 3 条、人格最多 1 条，留 before/after。

## 五、醒来

- 按睡眠质量恢复 `energy` 和 `mood_ceiling`（睡得差，第二天上限就低）。
- 温记忆里攒了一周的，看有没有共同点：反复出现的就是「我的脾气」，可以写进自述。
- 自述管腔调，不管有没有情绪——低落那天照样是她。

## 六、四条禁令

1. 不许有第二个「当前心情」。
2. 不许情绪在没有来源时大幅变动（会自激）。
3. 不许把日记当记忆再读回去（会自己照自己说话）。
4. 不许梦的内容直接改人格——只能改一次、只能一条、必须留痕。

## 七、还能挂进同一个状态里的

一个状态文件，能挂的都挂上，省得各自为政：

| 挂什么 | 影响什么 | 怎么算 |
| --- | --- | --- |
| 时间节律 | 语气、精力恢复 | 深夜话短、白天话多；凌晨恢复慢 |
| 关系值 | 对谁能开玩笑、能说多深 | 按人存一条，熟了就放宽，不熟的收着 |
| 未闭合清单 | 主动开口的**动机** | 有在等的事才主动，没有就别硬找话说 |
| 新料/兴趣 | 回血速度 | 刷到真感兴趣的东西，精力加回去 |
| 自我评价 | 声音的底色 | 今天觉得自己办得怎么样，影响话里那点底气 |
| 身体账 | 精力上限 | 熬了夜，第二天上限直接压低 |

挂进来的规矩不变：**只写这一个文件，每条变动带来源**。
